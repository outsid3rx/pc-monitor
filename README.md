# PC Monitor

Проект небольшого устройства для отслеживания нагрузки/температур на компоненты ПК.

## Сборка

![Схема сборки](./scheme.png)

## Запуск готового приложения

Создать файл шаблона по примеру `template.txt` (при необходимости добавить файл конфигурации) и запустить файл соответствующий системе.

## Установка зависимостей для сборки из исходников

Для установки зависимостей необходимо иметь `Node.js` и `npm` и выполнить следующие команды:

```bash
git clone git@gitlab.com:winterzz-dev/pc-monitor.git
npm install
```

## Запуск и конфигурация из исходников

1. Прошить Iskra Nano (или Arduino Nano) соответствующей прошивкой из `./ino/pc_monitor.ino`.
2. Отредактировать шаблон отображения в `template.txt` как из следующего раздела.
3. Если в компьютере несколько видеоадаптеров (встроенные модули так же считаются), то в файле `config.json` необходимо создать поле `gpuModel` и указать числовую модель видеокарты - приложение постарается самостоятельно определить нужное устройство. Например: `{"gpuModel": "3060"}` для видеокарты RTX 3060.
4. Собрать и запустить приложение командами `npm run build` и `npm run start`.

## Сборка из исходников

Для сборки требуется версия `18.5.0 Node.js`, для сборки выполнить команды:

```bash
npm run build:esbuild
npm install -g pkg
pkg .
```

После этого в папке `./bin` появятся готовые приложения.

## Настройка шаблонов

В файле `template.txt` нужно описать желаемое отображение информации в виде шаблонов - специальные токены будут заменены на значения в соответствии с таблицей:

| Токен    | Описание                                                                   |
|----------|----------------------------------------------------------------------------|
| %C-Ghz%  | Частота процессора в Гигагерцах (Ghz)                                      |
| %C-Temp% | Максимальная температура из всех ядер в градусах Цельсия                   |
| %C-Load% | Уровень загрузки процессора в процентах                                    |
| %G-Ghz%  | Частота видеоадаптера в Гигагерцах (Ghz)                                   |
| %G-Temp% | Максимальная температура из ядра и памяти видеоадаптера в градусах Цельсия |
| %G-Load% | Уровень загрузки видеадаптера в процентах                                  |
| %R-Used% | Загруженность ОЗУ в процентах                                              |
